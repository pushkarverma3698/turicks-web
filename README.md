## About

Turicks builds production-grade AI agent systems and SaaS platforms for founders — custom LangGraph pipelines, Next.js platforms, cloud infrastructure, and mobile apps. This repo is the public marketing site.

## Services

- **Custom AI Agents** — LangGraph multi-agent systems, RAG pipelines, Anthropic SDK integrations
- **SaaS Development** — Full-stack Next.js + MERN platforms, 3–5 day delivery
- **Cloud & DevOps** — CI/CD, monitoring, scaling, Vercel/AWS deployments
- **Mobile Apps** — iOS/Android (React Native)
